One image summing up Saturday 21 November 2026's world news, drawn as a
front page: Russia's biggest air assault of the war on Ukraine, with
missiles landing in Poland; the AI sell-off dragging Wall Street into
correction; Trump defending his Putin and Xi ties after the Shenzhen
summit; and GTA VI's record $3.79 billion first day.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, standard library only) copies the pre-rendered
`entry.png` — built by `render.py` with Pillow — byte for byte to
`$MAKEFUN_OUTPUT_DIR/entry.png`. No network, no randomness: two runs
write identical bytes.
